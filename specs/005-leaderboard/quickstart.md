# Quickstart: 005-leaderboard

Проверка ведётся на фикстурном бандле (SC-006: страница полностью работает без запуска пайплайна).

## Подготовка

```bash
cd web
npm install                    # если ещё не установлено
npm run fixture:bundle         # кладёт фикстурный бандл в web/data/
npm run dev
```

Открыть `http://localhost:5173/#/`.

## Сценарии (из Acceptance Scenarios спеки)

1. **Порядок и места** (US1 #1, #2) — команды идут по убыванию `total`; у команд с равным `total`
   одинаковый `rank` и стабильный порядок между перезагрузками (сверить с `web/data/index.json`
   фикстуры).
2. **Частичная оценка** (US1 #3, FR-003b) — команда с одной оценённой областью показывает пустую
   область как «—», не как `0`, и несёт бейдж частичной оценки.
3. **Переход на страницу команды** (US1 #4) — клик по названию ведёт на `/#/team/<team_id>`.
4. **Статусы и бейджи** (US2) — фикстура должна содержать по одной команде на каждый статус
   (`done`, `failed`, `no_data`, `running`) и минимум одну с `warnings`; навести на бейдж — виден
   `title`/доступное описание.
5. **Сортировка** (US3 #1) — клик по заголовку «Backend» переупорядочивает строки; `rank` в ячейке
   места не меняется (место остаётся привязанным к `total`, не к активной сортировке).
6. **Фильтр предупреждений** (US3 #2) — чекбокс «только с предупреждениями» оставляет только такие
   строки, состояние видно визуально (не только по списку).
7. **Ссылка с фильтрами** (US3 #3) — скопировать URL с `?sort=backend&dir=desc&warnings=1`, открыть
   в новой вкладке — состояние идентично.
8. **Пустой результат фильтра** (US3 #4) — выбрать фильтр, под который не попадает ни одна
   команда — `EmptyState` с кнопкой сброса, а не пустая таблица без объяснения.
9. **Ошибка загрузки** (US4 #3) — временно переименовать `web/data/index.json`, обновить страницу —
   виден `EmptyState` с описанием ошибки и повтором; вернуть файл, нажать «Повторить» — данные
   появляются без перезагрузки браузера.
10. **Узкий экран** (Edge Cases, FR-015) — DevTools на 360 px — карточки, а не таблица со
    скроллом вбок; место+название+итог в одной строке.
