# План исправлений валидации — 2026-09-22

Область: устранение расхождений обязательности полей в Go без изменения JSON Schema
или сгенерированных типов. Обязательные JSON-поля определяются по тегам типов,
сгенерированных из схемы; отсутствие и null отвергаются до потери этой информации.
Семантический валидатор продолжает проверять значения и ссылки на рубрику.

Валидатор рубрики проверяет именованные области, конечность весов и фиксированную
шкалу существующего контракта. Проверки: table-driven negative tests, явный нулевой
score и пустой warnings как положительные случаи, существующие контрактные фикстуры.

Полная эквивалентность всех ограничений JS и Go не заявляется этим исправлением.
