# Feature Specification: Web runner для безопасного запуска оценки — СНЯТА С ОБЪЁМА

**Feature Branch**: `011-web-runner`

**Created**: 2026-09-22

**Status**: Withdrawn (2026-09-22)

## Почему снята

Спека добавляла в интерфейс страницу запуска оценки и Go control plane на `/api/v1`, который
создавал job и запускал пайплайн по HTTP-запросу из браузера.

Решение владельца продукта от 2026-09-22 зафиксировало другой порядок работы: оператор клонирует
репозитории команд на свою машину, пайплайн обходит реестр и вызывает скиллы ревью, после чего
собирается бандл и статика. Запуск инициируется командой в терминале, а не формой в браузере.

Из этого следует, что control plane для запуска оценок не нужен:

1. **Нет адресата для запуска.** Интерфейс результатов — статика, публикуемая после прогона. Обращаться к API ему незачем:
   к моменту открытия страницы все данные уже в бандле.
2. **Возвращается главное свойство архитектуры.** Дашборд снова работает без сервера: открывается
   с файловой системы, обновляется копированием каталога. Пока существовал runner, часть
   функциональности требовала запущенного сервиса.
3. **Уходит поверхность атаки.** Форма, принимающая URL репозитория, Bearer-токен, ограничение
   числа активных прогонов, валидация хостинга — всё это нужно было только затем, чтобы веб-форма
   не стала shell-доступом. Без формы задача исчезает.

## Что уходит из кода

- `agent/cmd/web-runner` и `agent/internal/webapi` — HTTP control plane;
- `web/src/pages/runner` и `web/src/shared/api/runner.ts` — страница и клиент;
- `deploy/deploy-web-runner.sh`, `deploy/web-runner.service.example`,
  `deploy/nginx.docker.conf.example` — доставка и запуск сервиса;
- шаги сборки, упаковки и деплоя web-runner в `.github/workflows/ci-cd.yml`.

Статический деплой из спеки 010 сохраняется: он публикует собранный бандл и интерфейс.

## Уточнение от 2026-09-23

Веб-интерфейс получил отдельный локальный API для CRUD конфигурации команд. Он не создаёт jobs,
не запускает pipeline и не меняет оценки; решение о снятии web-runner остаётся в силе.

## Если решение изменится

Возврат потребует заново: control plane с аутентификацией и ограничением параллельности, страницы
запуска, доставки сервиса и правки принципа V конституции в части операций записи. Исходная
редакция спецификации доступна в истории git.
