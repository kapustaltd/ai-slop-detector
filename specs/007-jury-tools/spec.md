# Feature Specification: Инструменты жюри — СНЯТА С ОБЪЁМА

**Feature Branch**: `007-jury-tools`

**Created**: 2026-09-21

**Status**: Withdrawn (2026-09-21)

## Почему снята

Решение владельца продукта от 2026-09-21: платформа — внутренний инструмент **только для
просмотра**. Оценка, которую она выдаёт, — вспомогательная метрика, а не вердикт; решение
принимает жюри за пределами системы.

Из этого следует, что механики фичи 007 не нужны:

- **Переопределение оценок с комментарием** — жюри не правит баллы внутри системы; если оно не
  согласно с метрикой, оно просто взвешивает её иначе в своём решении.
- **Перезапуск оценки из интерфейса** — перезапуск выполняет оператор командой пайплайна
  (003 FR-004).
- **Пометка «проверено жюри»** — не имеет смысла без workflow проверки внутри системы.

Конституция приведена в соответствие: принцип V переформулирован из «последнее слово за жюри
через переопределение оценок» в «платформа не выносит вердикт и доступна только на чтение»,
версия конституции поднята до 2.0.0.

## Что сохранилось в других фичах

- Флаг `needs_review` при большом разбросе между прогонами остаётся — но как информация для
  жюри (003 FR-025, 005, 006), а не как задача, которую нужно закрыть в системе.
- Сырые отчёты модели и история прогонов сохраняются на диске (003 FR-016, FR-005) — для разбора
  спорных случаев вручную.
- Предупреждения (`warnings`), включая подозрение на prompt injection, видны в интерфейсе
  (006 FR-018).

## Если решение изменится

Возврат фичи в объём потребует: сервера или другого механизма многопользовательской записи,
правки принципа V конституции обратно и расширения контракта дата-бандла полями переопределений.
Исходная редакция спецификации доступна в истории git (коммит `ad46cd2` и последующие).
