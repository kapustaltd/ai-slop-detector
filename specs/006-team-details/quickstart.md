# Quickstart: 006-team-details

Проверка на фикстурном бандле (SC-004), тот же бандл, что использует 005 (`npm run
fixture:bundle`, `web/data/`). Открыть `http://localhost:5173/#/team/team-01`.

## Сценарии (из Acceptance Scenarios спеки)

1. **Radar по категориям с медианой** (US1 #1, #2) — открыть страницу команды с обеими областями:
   backend и frontend показаны раздельно, каждый radar — по категориям своей рубрики, с наложенной
   медианой (если оценённых команд ≥ 2, design-deviations.md пункт 2).
2. **Мало данных для медианы** (US1 #3) — фикстура с < 2 оценёнными командами: медиана/среднее не
   рисуются, есть явный текст об этом; профиль команды (radar) остаётся.
3. **Bar «команда против среднего»** (US1 #4) — по каждой категории видно отклонение от среднего.
4. **Drill-down до метрики** (US2 #1–2) — раскрыть категорию → подкатегорию → метрику: видны балл,
   `summary`, `rationale`, confidence, описание метрики и якоря 2/5/8/10 нужной версии рубрики.
5. **Подсветка и диапазон в сниппете** (US2 #3) — находка с `snippet` показывает код с подсветкой
   синтаксиса, номерами строк, выделен диапазон `line_start`–`line_end`.
6. **Постоянная ссылка** (US2 #4) — клик по рабочей ссылке находки открывает `permalink`.
7. **Непроверенная ссылка** (US2 #5) — находка с `link_status !== 'verified'` не показывает
   сниппет, помечена явно, что ссылка не проверена.
8. **Низкая уверенность видна** (US2 #6) — метрика с `confidence: 'low'` — пунктирная рамка,
   индикатор, причина словами; балл обычный.
9. **Распределение находок** (US3 #1–2) — счётчики strength/issue, разбивка по severity, клик по
   сегменту `SeverityBar` фильтрует список находок в дереве.
10. **Метаданные** (US4 #1–2) — SHA/версии/модель/время показаны; клик по SHA открывает коммит.
11. **Предупреждения** (US4 #3) — `warnings[]` показаны с пояснением (тот же словарь, что 005).
12. **Частичная область** (Edge Case) — область со статусом `no_data` показана как «нет данных»,
    графики по ней не рисуются, drill-down по ней не открывается.
13. **Ссылка с состоянием** (FR-021) — скопировать URL с `?area=backend&node=security.authz.
    resource-level`, открыть в новой вкладке — дерево раскрыто на том же месте.
14. **Узкий экран** (SC-006) — 360 px: страница остаётся пригодной к использованию (без
    горизонтальной прокрутки основного контента).
