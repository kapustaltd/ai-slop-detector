# Интерфейс платформы оценки

Приложение показывает рейтинг и разбор оценок. Страница `/manage/teams` добавляет запись в
YAML-реестр через API. Главная страница загружает актуальный индекс из `/api/bundle/index` и
обновляет его каждые 10 секунд; без этого маршрута показывает команды из реестра без оценки.
Статический бандл остаётся резервным источником, когда API отсутствует.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на адресе, который напечатает Vite. Данные берутся из `data/` — сейчас там
фикстурный бандл.

Для управления реестром запусти API в отдельном терминале из каталога `agent`:

```bash
test -f ../registry.yaml || cp ../registry.example.yaml ../registry.yaml
go run ./cmd/registry-api --registry ../registry.yaml --listen 127.0.0.1:8080
```

Открой `http://localhost:5173/#/manage/teams`. Список, добавление, изменение и удаление команды
доступны без токена. Для автоматической оценки API запускается с параметрами из
`deploy/registry-api.service.example` и с настроенным провайдером.

## Данные

Дата-бандл лежит в `data/` и подключается **импортом на этапе сборки**, а не запрашивается по
сети:

- `data/index.json` — индекс рейтинга, попадает в основной чанк;
- `data/teams/<team-id>.json` — данные команды, отдельный чанк на команду, грузится только при
  открытии её страницы.

При работающем API успешные оценки появляются без пересборки приложения. Все обращения к данным
проходят через `src/shared/api/bundle.ts`.

Типы данных генерируются из JSON Schema контракта 001 и бандла 004 командой
`npm run contract:generate`; `npm run check` проверяет, что сгенерированные файлы не устарели.

## Архитектура

Feature-Sliced Design. Слои снизу вверх: `shared` → `entities` → `widgets` → `pages` → `app`.
Импорт разрешён только вниз, обращение к внутренностям чужого среза запрещено — и то и другое
проверяется линтером, а не на ревью.

```
src/
  app/      инициализация: роутер (hash-режим), тема
  pages/    страницы: рейтинг, команда, управление реестром
  shared/   ui (компоненты shadcn), api (доступ к бандлу), lib, config
```

Слой `features` не заведён намеренно: управление реестром ограничено одной страницей, сортировка и
фильтры рейтинга живут внутри своих виджетов.

Слой `widgets` и `entities` появятся при реализации спек 005 и 006.

## Стек

Vite, React, TypeScript, shadcn/ui поверх Radix и Tailwind, TanStack Table, Recharts, Shiki,
React Router в hash-режиме, ESLint + Prettier, Vitest + Testing Library, steiger.

Маршрутизация в hash-режиме выбрана сознательно: прямые ссылки с фильтрами работают на любом
статическом хостинге без правил переписывания.

Внешних сетевых зависимостей для интерфейса нет: шрифт, иконки и стили локальные.
