# Добавление кода во фронтенд

Правила и запреты — в `web/CLAUDE.md`. Здесь порядок действий.

## Куда класть

| Что добавляешь | Слой | Пример пути |
|---|---|---|
| Страница по маршруту | `pages` | `src/pages/team/ui/team-page.tsx` |
| Составной блок страницы | `widgets` | `src/widgets/leaderboard-table/ui/leaderboard-table.tsx` |
| Представление доменной сущности | `entities` | `src/entities/team/ui/team-status.tsx` |
| Компонент оформления | `shared/ui` | только через `npx shadcn@latest add` |
| Утилита без домена | `shared/lib` | `src/shared/lib/format-score.ts` |

Вопрос «виджет или сущность»: сущность знает о доменном объекте и ничего о странице; виджет
собирает сущности в законченный блок. Если блок используется на одной странице и не имеет
собственного домена — оставь его в `pages/<страница>/ui`.

## Новый срез

1. Создай каталог среза и внутри него сегменты по назначению: `ui`, `model`, `api`.
2. Напиши `index.ts` — публичный API, только то, что нужно снаружи.
3. Импортируй в потребителе через `@/<слой>/<срез>`, а не по внутреннему пути.
4. Рядом с компонентом положи тест `<имя>.test.tsx`.
5. Проверь: `npx eslint src/<путь>` и `npm run lint:fsd`.

## Данные

1. Новое обращение к бандлу добавляется в `src/shared/api/bundle.ts`, а не в компоненте.
2. Данные команды загружаются асинхронно (`loadTeam`) — это отдельный чанк.
3. Отсутствие данных — это состояние, а не исключение: показывай «нет данных», а не пустоту.
4. Никаких вычислений баллов на клиенте: берутся готовые значения из бандла.

## Графики

1. Recharts через chart-компонент shadcn: `npx shadcn@latest add chart`.
2. Цвета — из CSS-переменных темы, чтобы график читался в обеих темах.
3. Обзорные графики строятся по категориям (8 backend / 7 frontend). Метрики — только в
   drill-down: 27 осей на radar нечитаемы.
4. Рядом с графиком должны быть доступны те же числа текстом.

## Подсветка кода

1. Shiki подключается лениво, только нужные языки.
2. Язык неизвестен — показывай простой текст с номерами строк, не падай.
3. Подсвечивается сниппет из бандла. Код из ответа модели не отображается как содержимое файла.

## Проверка результата

```bash
npx vitest run src/<путь>       # во время работы
npm run check                    # перед коммитом
```

Если менял состав чанков — убедись, что данные команд не попали в основной бандл:

```bash
npm run build 2>&1 | tail -15
```

В выводе должны быть отдельные файлы вида `dist/assets/team-*.js`.
